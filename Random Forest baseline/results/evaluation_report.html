Interpretation and reproducibility

  • Both tracks learn natural log(sold_price); the ensemble averages log predictions before exponentiating. Off-market never reads list_price.
  • Features follow the instruction whitelist. Structural lot NaN is retained; no imputation, scaling, text, price aggregates or sample weighting is used.
  • This is sale-month-cutoff evaluation. Some homes were listed before the cutoff, so it is not strict listing-day valuation.
  • Training/holdout gaps can reflect both overfitting and market drift. Trees do not reliably extrapolate an unseen market trend.
  • Official reports use rounded prices and include home-resampling bootstrap 95% intervals; these do not fully represent shared monthly market shocks.
  • Hidden June–September 2026 targets are unavailable. Submission validity does not measure hidden-test accuracy.
  • Every experiment preserves configuration, Python/package versions, code hashes, data hashes, predictions and diagnostics. Frozen configuration SHA-256: 961ee01dbecaaf3eeef945361d3c2de732d49ee7c01a3d836ab1d942be5a93b8.
